# Contributing to JorelTX ON

Thank you for your interest in contributing to **JorelTX ON**! 🎮

JorelTX ON is a community-oriented visual enhancement project for Roblox on Linux, primarily developed and tested with Sober.

Contributions, suggestions, bug reports and improvements are welcome.

---

## 🐛 Reporting Bugs

Before opening an issue, please make sure the problem has not already been reported.

When reporting a bug, include as much useful information as possible:

* Linux distribution and version
* Desktop environment
* X11 or Wayland
* GPU and driver version
* Sober version
* Roblox experience where the issue occurred
* JorelTX ON version
* Description of the problem
* Steps to reproduce the issue
* Screenshots or recordings when useful

Example:

```text
OS: Fedora Linux
Session: X11
GPU: NVIDIA RTX 3070
Driver: 595.71.05
Sober: [version]
JorelTX ON: V5.0.0

Problem:
The image becomes distorted when a specific effect is enabled.

Steps:
1. Launch Sober
2. Enable the effect
3. Join a Roblox experience
4. Observe the rendering
```

---

## 💡 Suggestions

Suggestions for new visual effects, compatibility improvements, performance optimizations and documentation are welcome.

When suggesting an effect, please explain:

* What the effect does
* Why it could be useful
* Whether it has already been tested
* Possible performance impact
* Any known compatibility issues

---

## 🔧 Pull Requests

If you want to contribute code, configuration or documentation:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test the changes with Sober when possible.
5. Make sure existing functionality is not unnecessarily broken.
6. Write a clear commit message.
7. Open a Pull Request.

For example:

```bash
git clone https://github.com/dadafa23/JorelTX-ON.git
cd JorelTX-ON

git checkout -b my-improvement
```

After making your changes:

```bash
git add .
git commit -m "Improve visual preset"
git push origin my-improvement
```

Then open a Pull Request on GitHub.

---

## 🎨 Visual Effects

JorelTX ON is primarily focused on visual enhancement.

When contributing a visual effect, consider:

* Image quality
* Performance
* Compatibility
* UI readability
* Cursor visibility
* Rendering stability

Effects that cause severe visual artifacts may not be included in the recommended preset.

---

## ⚡ Performance

Performance is an important part of the project.

A visual effect should not be considered an improvement if it introduces severe performance problems or makes the game difficult to use.

When possible, contributors should test both:

* Visual quality
* Performance impact

---

## 📋 Code and Configuration Guidelines

Please keep configuration files organized and readable.

Use descriptive names and comments when necessary.

Avoid unnecessary changes to unrelated files.

If a change is experimental, clearly identify it as experimental.

---

## 📖 Documentation

Documentation improvements are always welcome.

You can contribute by improving:

* Installation instructions
* Troubleshooting
* Configuration explanations
* Compatibility information
* Examples
* General project documentation

---

## 🤝 Community

Please be respectful and constructive when participating in the project.

Different hardware and configurations can produce different results.

Not every suggestion or contribution will necessarily be included in the default JorelTX ON configuration, but useful feedback is appreciated.
