# Changelog

All notable changes to JorelTX ON are documented in this file.

The format is based on the idea of keeping a simple version history for the project.

---

## [5.0.0] — 2026-09-19

### 🎉 JorelTX ON V5

The fifth major version of JorelTX ON.

This version focuses on visual enhancement for Roblox running through Sober on Linux.

### ✨ Added

* JorelTX ON V5 visual preset
* Image enhancement configuration
* Sharpening and visual-quality adjustments
* Configuration designed for Linux + Sober
* Public GitHub repository
* MIT open-source license
* Documentation for installation and configuration

### 🧪 Tested

JorelTX ON V5 was tested in a Linux environment using:

* Fedora Linux
* X11
* NVIDIA GPU
* Sober
* Roblox

### ⚠️ Experimental effects

Some post-processing effects were tested during development.

Certain effects produced undesirable rendering artifacts, including:

* Distorted image
* Fragmented-looking visuals
* Distorted cursor
* UI rendering artifacts

These effects were therefore not included as part of the recommended JorelTX ON V5 configuration.

### 📌 Notes

JorelTX ON is intended as a visual enhancement project.

It does not modify Roblox gameplay, game logic, player data or game files.

Compatibility and visual results may vary depending on:

* GPU
* Graphics driver
* Linux distribution
* Display server
* Sober version
* Roblox experience
* Rendering configuration
