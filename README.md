# JorelTX ON V5

> 🎮 Visual enhancement project for Roblox on Linux using Sober.

**JorelTX ON V5** is a personal visual-enhancement project created for Roblox on Linux, with a focus on improving the game's image quality while keeping the experience lightweight and practical.

The project was developed and tested with **Sober**, the Linux Roblox player.

---

## ✨ Features

JorelTX ON V5 focuses on visual enhancements such as:

* Improved image clarity
* Sharpening
* Contrast and color adjustments
* Visual depth enhancements
* Optional post-processing effects
* Performance-conscious configuration
* Designed for Linux + Sober

> ⚠️ Some effects may behave differently depending on the Roblox experience, Sober version, GPU, driver and rendering configuration.

---

## 🖥️ Compatibility

### Primary target

* Linux
* Sober
* Roblox

### GPU

The project is intended to work with modern GPUs supporting the required graphics features.

The original development environment used an **NVIDIA RTX 3070** on Linux.

Other GPUs may work, but results can vary.

## ⚠️ Important

JorelTX ON is a **visual enhancement project**.

It does not modify Roblox game files, game logic, gameplay mechanics or player data.

Visual effects may occasionally produce undesirable results depending on the rendering environment.

For example, certain post-processing effects can cause:

* Excessive sharpening
* Visual artifacts
* Distorted UI
* Glitched cursors
* Broken transparency
* Unexpected rendering behavior

If this happens, disable the problematic effect from the configuration.
